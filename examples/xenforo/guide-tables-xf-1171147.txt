[color=#2980b9][b]Purpose[/b][/color][divide=dotted][/divide]
The Table is made to display and format data in square cells.

The code table declares the contents to be inside of a table. The table accepts the options of 'none', 'dotted', and 'dark', which will change the borders of the table.

The code [B][U]tr[/U][/B] defines a table row, the amount of cells inside of all table rows needs to be equal after accounting for column spans. The tr accepts the option of 'grey' or 'gray' which will give the entire row a darker background. This is used to highlight a row.

The code [B][U]th, td, and tf[/U][/B] declare a table cell that is defined as a table header, table data and table footer, respectively. All of these codes accept the option of a number (such as td=2). This declares the column span, which will make the cell take up that man columns.
